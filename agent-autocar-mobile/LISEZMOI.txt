PUBLIER (voir la conversation pour le détail)
1. Sur github.com, crée un dépôt PUBLIC nommé  agent-autocar-web  (GitHub Pages gratuit exige un dépôt public).
2. Décompresse ce zip. Glisse TOUS les fichiers (pas le dossier, pas le zip) dans « Add file > Upload files ».
3. Settings > Pages > Source : « Deploy from a branch », branche main, dossier « / (root) » > Save.
4. Après 1 à 3 minutes, le site est à  https://TON-IDENTIFIANT.github.io/agent-autocar-web/
